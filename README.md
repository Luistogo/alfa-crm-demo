# α CRM · demostración

Prototipo navegable de **α CRM**, el CRM comercial del concesionario, para que el equipo lo pruebe y opine.

**Ábrelo aquí:** https://luistogo.github.io/alfa-crm-demo/

- **Todos los clientes son ficticios.** No contiene ni debe contener datos reales de clientes.
- Los cambios se guardan solo en tu navegador y se pierden al recargar.
- El dictado por voz funciona en Chrome y Edge: entra en un campo de texto y pulsa el micrófono (la primera vez el navegador pide permiso).
- Arriba, en "Ver como", puedes cambiar entre comercial y jefe de ventas.

Este repositorio solo publica la demostración. El proyecto completo está en un repositorio privado.
